# PhishShield: Explainable Real-Time Phishing URL Detector

PhishShield is a full-stack, machine-learning-based cybersecurity project designed to detect zero-day phishing URLs in real-time. It features a Manifest V3 Chrome Extension frontend that communicates with a local FastAPI backend, utilizing a Random Forest classifier to analyze lexical features and domain characteristics.

Unlike traditional blacklists, PhishShield uses Explainable AI (XAI) principles to not only classify a URL as safe or malicious but also to generate human-readable explanations detailing *why* a specific verdict was reached.

## 🚀 Key Features

* **Real-Time Lexical Analysis:** Extracts 15 structural data points from URLs, including digit ratios, entropy, and obfuscation markers, entirely independent of third-party threat feeds.
* **Explainable Output:** Provides direct, human-readable bullet points in the browser extension explaining the model's decision (e.g., highlighting high character entropy, raw IPv4 usage, or multiple hyphens).
* **DGA Heuristic Override:** Automatically identifies and flags structurally "normal" disposable domains generated by Domain Generation Algorithms (DGAs) commonly used in evasive campaigns.
* **Smart Whitelisting:** Bypasses ML inference for known safe domains (e.g., `github.com`, `apple.com`) to ensure minimal computational overhead and zero false positives on trusted infrastructure.
* **Normalized Input Processing:** Automatically handles short-form URLs and missing protocols to ensure accurate feature extraction.

## 🛠️ Technology Stack

**Frontend (Client)**

* HTML5 / CSS3 / JavaScript
* Google Chrome Extension API (Manifest V3)

**Backend (Server & ML)**

* **Framework:** FastAPI, Uvicorn
* **Machine Learning:** Scikit-Learn, Random Forest Classifier
* **Data Processing:** Pandas, Joblib
* **Dataset:** PhiUSIIL Phishing URL Dataset (UCI Machine Learning Repository)

## 🧠 Machine Learning Architecture

* **Algorithm:** Random Forest Classifier (150 estimators, balanced class weights).
* **Training Sample:** 50,000 balanced records to ensure robust generalization against benign internet traffic.
* **Decision Threshold:** Calibrated to 0.65 to drastically reduce false positive rates on standard web traffic.
* **Feature Extraction:** Extracts path length, subdomain count, numerical density, entropy mapping, HTTPS validation, and credential-harvesting keyword detection.

## ⚙️ Installation & Setup

### 1. Start the Backend API

You need Python 3.8+ installed on your system.

```bash
# Clone the repository
git clone https://github.com/Manit1508/phishing_url_extension.git
cd phishing_url_extension/backend

# Create and activate a virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install fastapi uvicorn pydantic scikit-learn pandas joblib

# Start the local server
uvicorn main:app --reload --host 127.0.0.1 --port 8000

```

*Keep this terminal window running in the background.*

### 2. Install the Chrome Extension

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Toggle **Developer mode** ON (top-right corner).
3. Click **Load unpacked** (top-left corner).
4. Select the `Frontend` folder located inside the cloned `phishing_url_extension` directory.
5. Click the puzzle piece icon in your Chrome toolbar and pin the **PhishShield** icon.

## 🧪 Testing & Demonstration

To demonstrate the full capabilities of the system, test the following scenarios directly in the extension popup:

1. **The Whitelist Test:** Scan `github.com` or `apple.com`. The system will instantly verify it against the local safe baseline, outputting a ~1% probability.
2. **The ML Inference Test:** Scan a standard, non-whitelisted article or blog. The ML model will evaluate the lexical structure and classify it as legitimate.
3. **The Zero-Day Evasion Test:** Scan a heavily obfuscated string or a known DGA payload (e.g., `www.vortex-sprout.net` or `[http://192.168.1.1/secure-update-login-account-verify](http://192.168.1.1/secure-update-login-account-verify)`). The system will flag the URL and provide specific explainability markers (e.g., "Hostname uses a hyphenated non-.com structure").
